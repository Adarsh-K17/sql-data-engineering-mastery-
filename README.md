# SQL for Data Engineering Mastery

A comprehensive repository of SQL scripts, dimensional data modeling exercises, analytical transformations, and data mart build pipelines using DuckDB, MotherDuck, and VS Code.

## Project Architecture

- 01_foundations/: Foundational SQL syntax (filtering, aggregation, joins).
- 02_advanced_sql/: CTEs, window functions, and semi-structured/nested data handling.
- 03_data_modeling_and_ddl/: Star schema design, DDL/DML, and query planning.
- projects/01_exploratory_data_analysis/: Analytical reporting on remote data engineering demand and salary trends.
- projects/02_warehouse_and_marts_etl/: Production ETL pipeline transforming cloud CSVs into an OLAP warehouse and downstream data marts.
